# Отчёт о выполненной работе

**Тема:** Парсинг вакансий и мониторинг рынка труда для профориентации школьников и студентов

**Выполнил:** Хайваз Никита Вадимович, группа 251-353, кафедра информационной безопасности, Московский политехнический университет

**Дата:** 16.11.2026

## 1. Цель

Создать программу, которая автоматически собирает вакансии с сайтов поиска работы и показывает понятную статистику по профессиям: спрос, зарплаты, требования к опыту и навыкам. Результат должен помогать школьникам и студентам выбирать профессию на основе реальных данных рынка труда.

## 2. Задачи

1. Выбрать источники вакансий и способ получения данных.
2. Написать модули сбора для каждого источника и привести данные к единому виду.
3. Организовать хранение данных и истории замеров.
4. Рассчитать показатели рынка по профессиям и сферам.
5. Сделать наглядный отчёт.
6. Проверить качество данных и устранить искажения.

## 3. Источники данных

| Сайт | Способ доступа | Результат |
|---|---|---|
| «Работа России» (trudvsem.ru) | открытые данные, без ключа | работает |
| SuperJob (superjob.ru) | официальный API, бесплатный ключ приложения | ключ получен, работает |
| HeadHunter (hh.ru) | официальный API | доступ закрыт (код 403) |

**Проблема с hh.ru.** При первом запуске API hh.ru ответил ошибкой 403 «forbidden». На портале разработчиков указано, что поддержка API для соискателей прекращена 15 декабря 2025 года, а регистрация приложений доступна только для работодателей. Получение данных в обход этого запрета (разбор страниц сайта) было отклонено как нарушение правил сайта. В программе оставлена поддержка hh.ru через официальный ключ: без ключа программа один раз выводит понятное сообщение и продолжает работу с другими сайтами.

**Решение.** Основными источниками стали государственный портал «Работа России» и SuperJob. Для SuperJob зарегистрировано приложение «Мониторинг рынка труда для профориентации» (ID 5314). Ключ хранится в переменной окружения Windows и в код не попадает.

## 4. Что сделано

### 4.1. Сбор данных
- Модули для трёх сайтов с общей логикой: паузы между запросами, повтор при ошибках сети и перегрузке сервера.
- Приведение к единому виду: зарплата в рублях, опыт в общей шкале (без опыта, 1-3, 3-6, более 6 лет), регион, работодатель, график работы, удалённая работа.
- Поиск навыков в тексте вакансии по словарю (52 навыка, включая навыки информационной безопасности: SIEM, DLP, пентест, ФСТЭК/152-ФЗ, криптография).
- Каталог из 35 профессий в 12 сферах с возможностью заменить его своим файлом.

### 4.2. Хранение
- База данных SQLite: вакансии, замеры, число вакансий на сайтах, снимки показателей для отслеживания динамики.

### 4.3. Аналитика
- Медиана зарплаты и типичный диапазон (половина вакансий платит в этих пределах).
- Зарплата по уровню опыта и отдельно для новичков.
- Доля вакансий без опыта и с удалённой работой.
- Популярные навыки, регионы, работодатели.
- Оценка «Старт» (0-100): насколько легко начать карьеру в профессии.
- Изменение спроса и зарплат по сравнению с прошлым замером.

### 4.4. Отчёт
- HTML-страница: общие показатели, три рейтинга, сравнение сфер, таблица профессий с сортировкой и фильтром, подробные карточки профессий, ссылки на вакансии для начинающих. Поддерживает светлую и тёмную тему, открывается на телефоне.
- Выгрузка всех вакансий в CSV для Excel и показателей в JSON.

### 4.5. Проверка качества данных
При анализе первого отчёта обнаружено, что у профессии «Сварщик» зарплата без опыта (275 тыс. ₽) выше средней по профессии. Проверка вакансий показала две причины искажения:

1. **Набор на военную службу по контракту** публикуется под названиями обычных профессий («Военнослужащий по контракту / Сварщик», работодатель «Минобороны России») с зарплатами 300-340 тыс. ₽. Добавлен фильтр по ключевым словам, такие объявления не учитываются - **отсеяно 152 объявления**.
2. **Одно объявление размещается во многих регионах** и учитывается многократно. Добавлено объединение повторов (тот же работодатель, название и зарплата) - **отсеяно 530 повторов**.

Также зарплата не показывается, если она указана меньше чем в 5 вакансиях, и не учитываются явно ошибочные суммы (меньше 10 тыс. и больше 2 млн ₽).

Для проверки данных добавлена команда `python main.py check <профессия>`.

## 6. Ограничения

- Нет данных hh.ru - крупнейшего сайта вакансий, поэтому по IT-профессиям выборка меньше реальной.
- Поиск идёт по названию профессии, часть вакансий с нестандартными названиями может не попасть в выборку.
- Зарплаты указаны так, как их пишет работодатель: часть до вычета налога, часть после.
- Фильтр военной службы работает по ключевым словам и может пропустить объявления без таких слов.

## 7. Итог

Создана программа на Python, которая собирает вакансии с двух сайтов (и готова к третьему), очищает данные от искажений, рассчитывает показатели рынка труда по 35 профессиям и строит наглядный отчёт для профориентации. Повторные запуски позволяют отслеживать изменения рынка во времени.
