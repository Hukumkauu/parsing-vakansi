# Мониторинг уровня заработных плат

Программа автоматически собирает вакансии с сайтов поиска работы, очищает данные, приводит названия должностей к единому виду и считает рыночные зарплаты (медиана, 25 и 75 перцентили) по заданным должностям и локациям. Результат сравнивается с вилками зарплат банка и записывается в Excel-файл с фильтрами и дашбордом.

Автор: Хайваз Никита Вадимович, группа 251-353, Московский политехнический университет.

## Зачем

Ручной сбор и нормализация данных по нескольким источникам занимает до 3 часов на одну позицию, а обновлять информацию нужно регулярно. Программа делает это за несколько минут по всем позициям сразу и может запускаться по расписанию.

## Excel-файл мониторинга

Вся работа идёт в одном файле `Мониторинг зарплат.xlsx`. Настройки меняются прямо в Excel, без участия разработчика.

| Вкладка | Кто заполняет | Что содержит |
|---|---|---|
| **Отчёт** | программа | должность, локация, медиана, 25 и 75 перцентили, число вакансий, источники, медиана по каждому источнику, дата актуальности, наша вилка, отклонение в % и статус «ниже рынка / в вилке / выше рынка» |
| **Дашборд** | программа | сводка по статусам, график «рынок и наша вилка», таблица и график динамики медианы по ролям |
| **Настройки мониторинга** | человек | список должностей и локаций, поисковые запросы, какие роли выводить на дашборд, источники, периодичность |
| **Наша зп** | человек | вилки зарплат банка: должность, локация, минимум, максимум |
| **Словарь должностей** | человек и программа | соответствия «название в вакансиях → единая должность»; новые соответствия программа добавляет с пометкой «авто (проверить)» |
| **Прочее (не по конфигурации)** | программа | вакансии, которые не вошли в отчёт, с причиной |
| **Вакансии** | программа | все вакансии, вошедшие в расчёт, со ссылками, для проверки |

Символ «/» в названии вкладки Excel запрещён, поэтому вкладка называется «Наша зп».

### Статусы

Медиана рынка сравнивается с вилкой банка:
- **ниже рынка** - медиана рынка выше верхней границы нашей вилки
- **в вилке** - медиана рынка внутри нашей вилки
- **выше рынка** - медиана рынка ниже нижней границы нашей вилки

Отклонение в % = (середина нашей вилки - медиана рынка) / медиана рынка.

## Как обрабатываются данные

1. **Сбор.** Для каждой строки «Настроек мониторинга» (должность + локация) запрашиваются вакансии со всех выбранных сайтов.
2. **Чистка.**
   - одна вакансия, найденная по разным запросам, учитывается один раз
   - повторы одного объявления (тот же работодатель, название и зарплата) учитываются один раз
   - объявления о военной службе по контракту не учитываются: они публикуются под названиями обычных профессий с зарплатами в разы выше рынка
   - явно ошибочные зарплаты (меньше 10 тыс. и больше 2 млн ₽) отбрасываются
   - выбросы (дальше трёх межквартильных размахов) отбрасываются
3. **Нормализация должностей.**
   - словарь соответствий: если название вакансии содержит фразу из словаря, должность берётся оттуда; «не учитывать» отправляет вакансию в «Прочее»
   - совпадение с названием должности из настроек: слова сравниваются по основам, слова уровня («ведущий», «старший», «senior») не мешают, опечатки допускаются
   - подбор похожего названия: если совпало не меньше двух третей слов, соответствие добавляется в словарь с пометкой «авто (проверить)»
4. **Расчёт.** Медиана, 25 и 75 перцентили по вакансиям с указанной зарплатой. Если вакансий меньше минимума из настроек, показатели не считаются («мало данных»).
5. **Сверка** с вкладкой «Наша зп» и расчёт отклонения.
6. **История.** Итоги каждого замера сохраняются в `data\history.db` для графиков динамики.

## Источники данных

| Сайт | Доступ |
|---|---|
| «Работа России» (trudvsem.ru) | открытые государственные данные, ключ не нужен |
| SuperJob (superjob.ru) | бесплатный ключ приложения |
| HeadHunter (hh.ru) | ключ приложения; с 15 декабря 2025 года hh выдаёт доступ в основном работодателям |

## Установка

Нужен Python 3.10 или новее.

```bash
pip install -r requirements.txt
```

### Ключ SuperJob

1. Зарегистрировать приложение на https://api.superjob.ru/register
2. Сохранить Secret key в переменной окружения (Windows), затем открыть новую командную строку:

```bash
setx SUPERJOB_KEY "ваш_ключ"
```

### Ключ HeadHunter (если есть)

```bash
setx HH_TOKEN "токен_приложения"
```

или `HH_CLIENT_ID` и `HH_CLIENT_SECRET`. Без ключа hh пропускается.

## Использование

| Команда | Что делает |
|---|---|
| `python main.py init` | создать файл `Мониторинг зарплат.xlsx` с примером настроек |
| `python main.py run` | собрать данные и обновить отчёт в файле |
| `python main.py run --open` | то же и открыть файл в Excel |
| `python main.py schedule` | запускать мониторинг автоматически (Планировщик Windows): еженедельно по понедельникам или 1-го числа каждого месяца, по полю «Периодичность» |
| `python main.py schedule --time 08:30` | то же, в указанное время |
| `python main.py unschedule` | отключить автоматический запуск |
| `python main.py run --file другой.xlsx` | работать с другим файлом |

Перед запуском закройте файл в Excel: открытый файл программа сохранить не сможет и сообщит об этом.

Файл можно открыть и в Google Таблицах: загрузить на Google Диск и открыть двойным щелчком.
