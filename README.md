# Мониторинг рынка труда для профориентации

Программа собирает открытые вакансии с российских сайтов поиска работы и считает статистику по профессиям: сколько вакансий, сколько платят, сколько платят без опыта, какие навыки требуют работодатели и в каких регионах больше всего работы. Результат - наглядный отчёт в браузере, который помогает школьникам и студентам выбрать профессию.

Автор: Хайваз Никита Вадимович, группа 251-353, Московский политехнический университет.

## Возможности

- Сбор вакансий с трёх сайтов:
  - **«Работа России»** (trudvsem.ru) - открытые государственные данные, ключ не нужен
  - **SuperJob** (superjob.ru) - бесплатный ключ приложения
  - **HeadHunter** (hh.ru) - подключится автоматически, если появится ключ приложения
- **35 профессий из 12 сфер**: IT, информационная безопасность, инженерия, рабочие профессии, медицина, образование, экономика, торговля, маркетинг и медиа, сфера услуг, логистика
- **Отчёт в браузере**:
  - общие показатели рынка
  - рейтинги: самые высокие зарплаты, самый большой спрос, легче всего начать без опыта
  - сравнение сфер деятельности
  - таблица всех профессий с сортировкой и фильтром по сфере
  - карточки профессий: зарплата по опыту, требуемые навыки, регионы, работодатели, вакансии для начинающих
  - динамика рынка между замерами
- **Таблица для Excel** со всеми вакансиями (`reports\vacancies_ДАТА.csv`) и показатели в JSON (`reports\stats_ДАТА.json`)
- **Чистка данных**:
  - объявления о военной службе по контракту не учитываются: они публикуются под названиями обычных профессий с зарплатами в разы выше рынка
  - одно и то же объявление, размещённое во многих регионах, считается один раз
  - явно ошибочные зарплаты (меньше 10 тыс. и больше 2 млн ₽) не учитываются
  - зарплата не показывается, если она указана меньше чем в 5 вакансиях
- **История замеров** в базе SQLite (`data\vacancies.db`) - при повторных запусках видно, как меняется рынок

## Установка

Нужен Python 3.10 или новее.

```bash
pip install -r requirements.txt
```

### Ключ SuperJob

1. Зарегистрировать приложение на https://api.superjob.ru/register
2. Сохранить Secret key в переменной окружения (Windows):

```bash
setx SUPERJOB_KEY "ваш_ключ"
```

3. Закрыть и заново открыть командную строку.

### Ключ HeadHunter (необязательно)

С 15 декабря 2025 года hh.ru выдаёт доступ к поиску вакансий только по ключу приложения, и регистрируют приложения в основном для работодателей. Если ключ есть, его нужно задать одним из способов:

```bash
setx HH_TOKEN "токен_приложения"
```

или

```bash
setx HH_CLIENT_ID "client_id"
setx HH_CLIENT_SECRET "client_secret"
```

Без ключа программа один раз сообщит, что hh недоступен, и продолжит работу с остальными сайтами.

## Использование

| Команда | Что делает |
|---|---|
| `python main.py collect` | собрать вакансии по всем профессиям и построить отчёт |
| `python main.py collect --limit 100` | брать до 100 вакансий с каждого сайта на профессию |
| `python main.py collect --sphere IT` | только одна сфера (можно указать несколько раз) |
| `python main.py collect --profession сварщик` | только одна профессия (можно часть названия) |
| `python main.py collect --region москва` | только один регион (по умолчанию вся Россия) |
| `python main.py collect --sources superjob trudvsem` | выбрать сайты |
| `python main.py report --open` | построить отчёт по последнему замеру и открыть в браузере |
| `python main.py stats` | краткая сводка в командной строке |
| `python main.py check сварщик --junior` | самые дорогие вакансии профессии (только без опыта) |
| `python main.py list` | список профессий в каталоге |

Свой список профессий можно положить в файл `professions.json` рядом с `main.py`:

```json
[
  {"name": "Программист Python", "sphere": "IT", "query": "python разработчик"},
  {"name": "Повар", "sphere": "Сфера услуг", "query": "повар"}
]
```

## Устройство программы

```
main.py                      команды запуска
vacancy_monitor/
  sources/
    base.py                  общие HTTP-запросы: повторы, паузы между запросами
    trudvsem.py              «Работа России»
    superjob.py              SuperJob
    hh.py                    HeadHunter
  professions.py             каталог профессий
  collector.py               сбор вакансий по каталогу
  storage.py                 база данных SQLite
  filters.py                 отсев военной службы и повторов
  skills.py                  поиск навыков в тексте вакансии
  analytics.py               расчёт показателей
  report.py                  HTML-отчёт, CSV и JSON
  models.py                  описание вакансии, шкала опыта
```

Порядок работы: `collector` берёт профессии из каталога и для каждой запрашивает вакансии у всех сайтов. Ответы сайтов приводятся к единому виду (`Vacancy`): зарплата переводится в рубли, опыт - в общую шкалу «без опыта / 1-3 / 3-6 / более 6 лет», навыки находятся по словарю. Вакансии сохраняются в базу вместе с номером замера. `analytics` считает медиану и типичный диапазон зарплат, долю вакансий без опыта, долю удалённой работы, популярные навыки и оценку «Старт» (0-100) - насколько легко начать карьеру в профессии. `report` собирает всё в одну HTML-страницу без внешних зависимостей.
