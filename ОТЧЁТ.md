# Отчёт о выполненной работе

**Проект:** Мониторинг уровня заработных плат

**Выполнил:** Хайваз Никита Вадимович, группа 251-353, кафедра информационной безопасности, Московский политехнический университет

## 1. Актуальность и проблема

Ручной сбор и нормализация данных о зарплатах по нескольким источникам занимает до 3 часов на одну позицию, а информацию по ключевым вакансиям нужно обновлять регулярно. Нет единого автоматизированного инструмента, который даёт актуальные, сопоставимые и проверяемые данные по зарплатам для заданных должностей и локаций.

## 2. Цель

Создать инструмент с настраиваемыми параметрами, который по расписанию формирует отчёт по рыночным зарплатам (медиана, 25 и 75 перцентили) по заданным должностям и локациям и сравнивает их с вилками зарплат банка.

## 3. Выполнение ключевых задач

| Задача из ТЗ | Что сделано |
|---|---|
| 1. Источники данных и гибкая выборка по локациям и должностям | Подключены «Работа России» (открытые данные) и SuperJob (официальный API, получен ключ приложения), подготовлен модуль HeadHunter. Список должностей, поисковых запросов и локаций задаётся во вкладке «Настройки мониторинга». |
| 2. Нормализация названий должностей | Словарь соответствий во вкладке «Словарь должностей» плюс автоматический подбор похожих названий по основам слов с допуском опечаток. Новые соответствия программа сама добавляет в словарь с пометкой «авто (проверить)». |
| 3. Цепочка «собрать → убрать дубли и ошибки → посчитать» | Реализована в модуле `pipeline.py`: повторы, объявления о военной службе, ошибочные зарплаты и выбросы отсеиваются, затем считаются медиана и перцентили. |
| 4. Сверка с вилками банка | Вкладка «Наша зп» заполняется вручную. Для каждой позиции считается отклонение в % и статус «ниже рынка / в вилке / выше рынка». |
| 5. Отчёт в Excel с фильтрами, настройками и дашбордом | Один файл Excel: «Отчёт», «Дашборд», «Настройки мониторинга», «Наша зп», «Словарь должностей», «Прочее (не по конфигурации)», «Вакансии». Во всех таблицах есть фильтры, статусы выделены цветом, на дашборде графики рынка и динамики. |

## 4. Продуктовый результат

**Отчёт** - столбцы: должность, локация, медиана, 25 и 75 перцентили, число вакансий, источник, медиана по каждому источнику (для сверки источников между собой), дата актуальности, наша вилка, отклонение в % и статус.

**Настройки мониторинга** - таблица должностей и локаций (включить или выключить строку, вывести роль на дашборд) и параметры: источники, число вакансий, минимум вакансий для расчёта, периодичность.

**Наша зп** - ручной ввод вилок по должностям и локациям.

**Словарь должностей** - пополняется вручную и автоматически.

**Прочее (не по конфигурации)** - вакансии, не вошедшие в отчёт, с причиной: не совпала должность, исключено словарём, другая локация.

**Дашборд** - число позиций по статусам, график «медиана рынка и наша вилка», таблица и график динамики медианы по ролям между замерами.

**Автоматический запуск** - команда `python main.py schedule` создаёт задание в Планировщике Windows: еженедельно или ежемесячно, в зависимости от настройки.

## 5. Технические решения

- Язык Python, библиотеки `requests` (запросы к сайтам) и `openpyxl` (Excel).
- Excel-файл одновременно хранит настройки и результат: человек меняет настройки, программа пересоздаёт только свои вкладки и не трогает ручные.
- История замеров хранится в SQLite для графиков динамики.
- Ключи API хранятся в переменных окружения Windows и не попадают в код.

## 6. Ограничения и проблемы

- **HeadHunter.** API hh.ru отвечает ошибкой 403: с 15 декабря 2025 года доступ к поиску вакансий выдаётся в основном работодателям. Получение данных в обход этого запрета не использовалось. Модуль hh подключится, если появится ключ приложения.
- **Источники.** Сейчас работают 2 источника из 3-5 по ТЗ. Архитектура позволяет добавить новый сайт отдельным модулем.
- **Нормализация** выполняется словарём и алгоритмом подбора похожих названий, без платных внешних сервисов. Автоматически найденные соответствия нужно проверять вручную.
- **Зарплаты** указаны так, как их пишет работодатель: часть до вычета налога, часть после.
- **Google Sheets.** Отчёт формируется в Excel; файл открывается в Google Таблицах после загрузки на Google Диск.

## 7. Итог

Создан инструмент мониторинга рыночных зарплат: сбор с нескольких сайтов, чистка, нормализация должностей, расчёт медианы и перцентилей, сверка с вилками банка и отчёт в Excel с дашбордом. Все настройки меняются в Excel без участия разработчика, обновление может запускаться автоматически по расписанию.
